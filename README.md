
# Community Garden Planner

## Project Description
Community Garden Planner is a Python-based application that helps users manage community gardens.

## Features
- Add garden records
- View all garden records
- Search plants
- Update records
- Delete records
- Executive summary
- Harvest alerts
- Export CSV reports
- Export Markdown reports
- Generate charts using Matplotlib
- Store data using JSON

## Technologies Used
- Python
- JSON
- CSV
- Matplotlib

## Installation

Install the required library:

pip install -r requirements.txt

## How to Run

python main.py
